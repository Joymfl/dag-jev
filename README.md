# Running

`cargo run`

output in `core/out`

change `input.txt` for changing the input for the test

generate control input for testing Jev output
generated by `python generate_control.py` needs to be filled in by you

structure is `dep_{}_{}: 0/1` 0 for not dependant, 1 for dependant

# Graph Viz

runs from `viz-frontend`. `cargo run` writes graph state (only pre condensation for now) into `/core/out` and viz-frontend reads off that.
